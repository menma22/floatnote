# Floatnote 要件・設計 v7

作成日: 2026-11-01。前版: [v6](spec-v6.md)。本人の追加依頼「macにも対応させてほしい」を反映する。

## 対応範囲

- Windows x64 に加え、macOS の Apple Silicon と Intel で使えるアプリを配布する。Mac 用は両アーキテクチャを含む Universal 版とし、DMG と ZIP を用意する。
- 本文、色、ヘッダーのホバー表示、周期、保存、一覧、入力を奪わない再表示は同じ実装を使う。
- macOS の標準メニュー、終了、コピー・貼り付け・取り消し、および Command キーでの新規作成・一覧表示を使えるようにする。Windows の既存操作は保持する。
- Windows 側だけで Mac 対応済みとは扱わない。GitHub Actions の実際の macOS runner で、ビルド・編集・保存・再表示・配布アプリ起動を確認する。
- 対応する最小 macOS バージョンは、利用する Electron の一次情報と生成物の情報から確かめる。推測した数値は記載しない。

## 公開とインストール

- 新しい Release に Windows インストーラーと Mac 用 DMG/ZIP、各ファイルの SHA256SUMS をまとめる。旧版の Release・タグ・配布物を上書きしない。
- AI に渡すインストール案内は、OS と CPU を確認し、同じ最新 Release のファイルとチェックサムを取得する。Mac ではアプリを Applications へ置いて起動する。
- 署名・notarization の有無は確認して説明する。Apple の署名情報や契約を取得できていない場合は、署名済みと称したり、セキュリティ設定を自動で弱める案内を追加したりしない。

## 成功条件の追加

| ID | 条件 |
| --- | --- |
| M1 | macOS 上で既存の編集・保存・周期再表示の操作テストが成功する |
| M2 | macOS で Command ショートカットと標準編集メニューを使える |
| M3 | Universal 版に Apple Silicon/Intel の実行コードを含むことを生成物で確認する |
| M4 | 生成した Mac アプリ自体が起動し、淡い黄緑の付箋を編集・保存できる |
| M5 | 公開 Release に OS ごとのファイルと正しいチェックサムが揃い、インストール案内から辿れる |

v6 の H1〜H5 も両 OS の実装・検証対象とする。
