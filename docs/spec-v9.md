# Floatnote 要件・設計 v9

2026-11-02。前版 [v8](spec-v8.md) の成功条件を継承し、表示方式を改訂する。

v8の `did-finish-load` 待ちでも、デバッガーを接続していない普段使いの実行環境で付箋が非表示のままになる事象を観測した。表示を `ready-to-show` と `did-finish-load` のいずれにも依存させない。新規付箋と一覧は作成・読み込み開始直後に表示し、本文の読み込みを可視状態で進める。起動時の保存済み付箋は従来どおり `showInactive()` とし入力を奪わない。定期再表示のコードは変更しない。

デバッガーを接続した速度検査に加え、実際に使用するアプリでもウィンドウが表示されることを確認する。v4の検証記録は中間実装の記録であり、最終方式の証拠として扱わない。
