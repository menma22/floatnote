# Floatnote 実装照合・検証 v6

2026-11-02。[要件 v10](spec-v10.md)、前版 [v5](verification-v5.md)。

## 色パレットの修正

`src/main.js` で付箋の `pointerleave` によるパレットの閉鎖を削除した。既存の色選択・ボタン再クリック・外側クリック・Esc・付箋閉鎖で閉じる処理は保持している。`src/style.css` ではパレットが開いている間ヘッダーを表示し、パレットを `no-drag` にした。

既存の実操作検査を変更し、パレットを開く→ポインターを付箋の外へ移動→パレットが表示されたままであることを確認→戻ってブルーを選ぶ→背景色が変わりパレットが閉じる、という経路が成功した。閉じたあとのホバーヘッダーとキーボード移動の検査も同じケース内で成功した。整形・ESLintも成功。今回の変更に関係しない全テストは繰り返していない。

## このPCへの適用

Windows 0.1.3のインストーラーを生成して適用し、終了コード0、配置先EXEのバージョン0.1.3、配置先 `resources/app.asar` と生成物のSHA256一致を確認した。本文・色・周期を含むメモ7枚は、更新前に保存・バックアップしたJSONとバイト単位で一致した。更新直後のインストーラー失敗は再実行前に配置先ファイルを排他的に開けることを確認してから対処した。

公開Releaseは今回更新していない。Macでの今回の追加検証は未実施。前版に記録した既存の未解決事項を解消したとは扱わない。
