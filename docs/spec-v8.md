# Floatnote 要件・設計 v8

作成日: 2026-11-02。前版: [v7](spec-v7.md)。既存要件を継承する。

## 操作の即時反映

本人の依頼: 「プラスボタンとかあの一覧ボタンとかを押してもすぐに作成されない」「ちゃんと即時で反映されるように」。

- ＋で新しい付箋、一覧ボタンで付箋一覧が、操作直後に画面の手前に表示され操作可能になる。
- DOM の存在だけでは成功としない。実際のネイティブウィンドウの可視状態と本文・一覧を確認する。通常の検証環境で操作から1秒以内を目標とする。
- 非表示ウィンドウの初回描画通知に表示を依存させず、ページ読み込み完了で表示する方針を検証する。既存一覧の再利用時も手前に表示する。
- 定期再表示の「入力フォーカスを奪わない」動作、保存と終了処理は保持する。
- 修正版を作成し、このPCのインストール済みアプリにも反映する。利用中のメモはバックアップし保持する。

## 未検証事項

初回描画通知の待機が実際の遅延原因か、変更前後の実行結果で判定する。Mac実環境での追加確認はWindowsの結果と区別する。
