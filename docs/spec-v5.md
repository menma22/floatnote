# Floatnote 要件・設計 v5

作成日: 2026-11-01。前版: [v4](spec-v4.md)。利用者向けのサイズ・色・機能要件は変更せず、実機で判明した寸法保存の条件を具体化する。

## Windows の表示倍率と寸法保存

150% 表示の Windows 実機で、`setBounds({width:320,height:240})` に対し、外枠を含む `getNormalBounds()` は 321×241、`getContentSize()` は 320×240 を返した。外枠の寸法を再起動時に渡すと、再起動のたびに付箋が大きくなることを E2E で確認した。

- 新規・復元ウィンドウは生成直後に、意図した寸法を `setBounds()` で再適用する。
- 保存する `bounds` は、通常状態の外側の位置 `x,y` と、本文領域の論理寸法 `width,height` を組み合わせる。固定のピクセル補正値は使わない。
- 最大化・最小化中は、直前の通常状態の保存寸法を維持する。
- 生成時に通常状態を保存し、直後に最小化・最大化されても復元寸法を失わない。

成功条件 A7 に「再起動を繰り返しても意図しない寸法拡大が起きない」を追加する。表示倍率による外枠の端数と、利用者が操作する本文領域のサイズは区別して検証する。
