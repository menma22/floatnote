# Floatnote 要件・設計 v3

作成日: 2026-11-01。前版: [v2](spec-v2.md)。v1・v2 の要件を引き継ぎ、初期サイズと既定色を以下へ変更する。

本人の追加依頼: 付箋はもう少し小さく「半分ぐらい」、既定色は Windows の黄色と異なる「蛍光黄緑」。

## 確定した変更

- 新規付箋のサイズは **340×240**。従来の 420×380 と比較して面積が約 51% になる。最小サイズは **320×180**。両辺を半分にすると本文や操作が実用的でなくなるため、面積を約半分にする。
- ヘッダーは約 36px 高。必要な全操作と周期スライダーを 1 段で維持し、320px 幅でも横にはみ出さず、ドラッグできる余白を残す。
- 新規付箋の既定色は **ライム（蛍光感のある黄緑）**。濃い文字との可読性を優先する。アプリのアイコンもライムへ合わせる。
- パレットの 6 色はライム、セージ、ブルー、ローズ、ラベンダー、グレー。内部の `color` に `lime` を追加する。新規・色未指定データは `lime` を使う。以前に明示的に保存した `cream` は保持し、既存メモを勝手に塗り替えない。
- 保存済みのサイズは引き続き復元する。新しい初期サイズを既存付箋へ強制適用しない。

## 成功条件の更新

| ID | 更新後の条件 | 確認方法 |
| --- | --- | --- |
| A1 | 初回は 340×240 のライム色の付箋が 1 枚だけ開く | Electron E2E・画面確認 |
| A11 | 6 色を選択でき、既定はライム。保存済み色を再起動後も保持 | E2E・単体テスト・画面確認 |
| A12 | 320px 幅でヘッダーが 1 段に収まり、本文を表示できる | DOM 寸法計測・画面確認 |

周期到達時のフォーカス非取得、30 分の初期周期、保存、Markdown、一覧などは変更しない。
