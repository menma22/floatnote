# Floatnote 要件・設計 v10

2026-11-02。前版 [v9](spec-v9.md) を継承し、色選択中の表示を修正する。

本人の報告: 「色も変えるときに、パレットは出るけど、カーソル動かしたらパレット消える」。

パレットを開いたあとはポインターが付箋の外へ移動しても閉じない。閉じる条件は色の選択、色ボタンの再クリック、パレットと色ボタン以外のクリック、Esc、付箋を閉じる操作とする。開いている間はヘッダーを表示して色ボタンを操作可能にし、パレット全体をウィンドウのドラッグ対象から除外する。選択した色の保存と、閉じたあとの通常のホバーヘッダー動作を保持する。

既存の実操作検査を更新し、パレットを開く→付箋の外へ移動→戻って別の色を選ぶ、の経路を確認する。このPCのインストール済みアプリにも修正版を反映し、本文と周期設定を保持する。
