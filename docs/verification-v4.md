# Floatnote 実装照合・検証 v4

2026-11-02。[要件 v8](spec-v8.md)、前版は [v3](verification-v3.md)。

## 変更と実測

`electron/main.cjs` の新規付箋と一覧の表示を、非表示状態での初回描画イベント `ready-to-show` 待ちから `webContents` の `did-finish-load` に変更した。一覧は表示時に明示的にフォーカスする。既存一覧の再利用、保存、周期再表示の実装は変更していない。

インストール済み0.1.1を分離した一時データで検証すると、＋の1クリックからネイティブウィンドウが表示され操作可能になるまで4814msかかり、1秒未満の検査に失敗した。修正したソースでは＋354ms／一覧311ms、再確認で＋331ms／一覧319msだった。この比較は本PCでの実測で、全環境の時間保証ではない。

`tests/e2e/app.spec.js` に1秒未満の実測検査を追加し、DOMの存在に加えてネイティブウィンドウの `isVisible()` を検査する。起動時も実ウィンドウの表示を待って操作するようにした。

## 確認結果と制限

- コード整形・ESLint: 成功。単体テスト35件: 成功。
- Windowsのヘッダー表示、複数付箋・Markdown・色・周期・再起動保存、不正IPC拒否と閉じたメモの保持: 成功。
- 新規付箋と一覧の応答時間: 成功。
- 最小化した付箋の定期再表示で入力を奪わない検査: 本PCでは失敗。表示後に `isFocused()` が true になる。修正前のインストール済み0.1.1でも同じ検査が同じ箇所で失敗した。今回の表示遅延修正で解消したとは扱わず、既存の未解決事項として追跡する。
- Macの実環境での追加検証は本作業では未実施。v3の検証結果を今回の変更の検証結果とはしない。

Windowsの修正版は0.1.2として生成する。公開Releaseの更新状況とこのPCへの適用状況は、生成成功と区別する。
