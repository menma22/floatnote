# Floatnote 要件・設計 v6

作成日: 2026-11-01。前版: [v5](spec-v5.md)。付箋の保存・周期・色・寸法は引き継ぎ、表示と配布案内だけを更新する。

本人の依頼: 「カーソルを合わせていないときはヘッダー出ない」「本当に付箋のメモの部分だけ」「カーソルを合わせたらヘッダー出てくる」。また、誰でもダウンロードして使え、PC を操作できる AI へインストールを頼める導線を確認・整備する。

## ヘッダーの振る舞い

- 付箋にカーソルが重なっていないときは、ヘッダーの操作・背景・区切り線を隠して、付箋だけに見せる。
- カーソルが付箋へ入ると既存のヘッダーを表示し、外へ出ると再び隠す。表示・非表示で本文・キャレット・スクロール位置を上下に動かさない。
- 本文の編集フォーカスや周期による再表示だけではヘッダーを表示しない。
- キーボードでヘッダーへ移動したときは、操作対象が見えるよう表示する。マウスで押したボタンにフォーカスが残っただけでは表示を固定しない。
- 開いた色パレットはカーソルが付箋の外へ出たら閉じる。キーボードでパレットを操作する間は必要な操作を表示する。
- 一覧ウィンドウのヘッダーは常時表示する。

## 配布

- 更新を v0.1.1 の Windows x64 インストーラーとして公開する。既存 v0.1.0 の Release やタグは変更しない。
- README は一般利用者向けインストールと開発者向けビルドを区別し、最新版へのリンクと、AI に渡せるインストール依頼を用意する。
- アプリ本体に Node.js などの事前インストールは不要。未署名という制約と、PC を操作する権限のない AI はインストールできない点は正確に説明する。

## 成功条件

| ID | 確認内容 |
| --- | --- |
| H1 | カーソル外ではヘッダーが見えず、内では表示され、再び外へ出ると隠れる |
| H2 | 切替前後で本文の位置・内容・スクロール位置が変わらない |
| H3 | 本文フォーカスだけでは表示されず、キーボードのヘッダー操作は見える |
| H4 | 色パレットを開いてもカーソル外で操作が残らず、一覧のヘッダーは常時使える |
| H5 | 公開インストーラーとチェックサムが取得でき、AI 用の案内から最新版へ辿れる |

CSS と必要なパレット終了処理だけで実装し、保存・タイマー・ネイティブウィンドウ制御は変更しない。実際の Electron 画面と配布実行ファイルで対象の振る舞いを確認する。
