# Floatnote 要件・設計 v4

作成日: 2026-11-01。前版: [v3](spec-v3.md)。サイズ・機能・保存の要件は引き継ぎ、既定色の表現だけを改訂する。

本人の修正依頼: 「白強める感じ」「薄い、薄い黄緑」。

- ライム色の本文背景は白を多く混ぜた **淡い黄緑 `#efffc9`** とする。
- ヘッダーは近い色の `#e7f5bd`、枠線は `#d1dfa4`。濃い文字を維持する。
- 初回描画時のウィンドウ背景とアプリのアイコンも同じ淡い黄緑へ合わせる。
- 340×240 の初期サイズ、320×180 の最小サイズ、30 分の初期周期、6 色の選択、フォーカスを奪わない再表示は変更しない。

成功条件 A11 の既定色の目視確認は、この淡い黄緑を基準とする。
